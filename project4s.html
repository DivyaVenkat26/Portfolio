Introduction:

This project focuses on analyzing restaurant sales data using SQL. The objective is to uncover patterns in menu preferences, customer order behavior, and overall sales trends to support business decisions.

Data Preparation:

  1. Data Source: Raw transactional dataset of a fictional pizza chain.
  2. Data Platform: MySQL for query execution.
  3. Data Cleaning: Null handling, column renaming, formatting dates.

SQL Analysis:

  • Best Selling Items:

    • Finds top 5 most ordered menu items.

    SELECT mi.item_name, COUNT(*) AS order_count FROM order_details od JOIN menu_items mi ON od.item_id = mi.menu_item_id GROUP BY mi.item_name ORDER BY order_count DESC LIMIT 5
  • Total Orders:

    • Calculates the total number of unique customer orders.

    SELECT COUNT(DISTINCT order_id) AS total_orders FROM order_details;
  • Average Order Value:

    • Computes the average revenue generated per order.

    SELECT ROUND(SUM(mi.price)/COUNT(DISTINCT od.order_id), 2) AS Average_Order_Value FROM order_details od JOIN menu_items mi ON od.item_id = mi.ï»¿menu_item_id;
  • Revenue by Category:

    • Shows total revenue and percentage contribution for each menu category.

    SELECT mi.category,SUM(mi.price) AS revenue,ROUND(SUM(mi.price) * 100.0 / (SELECT SUM(price) FROM menu_items),1) AS percentage FROM order_details od JOIN menu_items mi ON od.item_id = mi.menu_item_id GROUP BY mi.category
  • Peak Hourly Sales:

    • Identifies the hours of the day with the highest number of orders.

    SELECT HOUR(order_time) AS hour, COUNT(*) AS order_count FROM order_details GROUP BY hour ORDER BY order_count DESC;

KPIs:

  • Total Orders Placed: 5,370
  • Avg Order Value: $29.8
  • Avg Items per Order: 2.28

Key Insights:

  • Best-selling item is *Hamburger*
  • Monday drives 21% of weekly sales (unusually strong), while weekends underperform
  • Peak ordering time: 12 to 1 PM and Evening : 5 to 7 PM
  • Italian food makes the most money, while American dishes need improvement to keep up
