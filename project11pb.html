Uber Trip Analysis

Power BI Project

  1. Home
  2. Uber Trip Analysis

Introduction:

This project involved building an interactive Power BI dashboard to analyze cab booking data and uncover insights on trip trends, revenue, and customer behavior. The goal was to identify peak booking times, popular routes, and performance patterns to support data-driven decision-making.

Data Preparation:

  1. Data Quality Check:

    Verified and cleaned data in Power Query to ensure accuracy and consistency.

  2. Data Modeling:

    Created relationships between Location, Trip Details, and Calendar tables using Location ID and Pickup Date.

  3. Data Type Adjustment:

    Modified column data types and removed unnecessary fields for better performance.

  4. Calculated Columns:

    Generated new columns in Power BI:

    • Pickup Hour (HH:MM:SS): Extracted from Pickup Time for hourly analysis.
    • Pickup Date: Derived from Pickup Timestamp for date-wise aggregation.
    • Trip Type (Day/Night): Classified trips based on pickup hour to compare travel patterns.

Measures / KPIs:

DAX queries were used to calculate all KPIs and performance metrics.

  1. Total Booking Amount: $1.6M
  2. Total Bookings: 104K
  3. Avg Booking Amount: $15K
  4. Avg Trip Distance: 3.4 miles
  5. Total Trip Distance: 349K miles
  6. Avg Trip Time: 16 minutes
  7. Most Frequent Pickup: Penn Station / Madison Sq West
  8. Most Frequent Drop-off: Upper East Side North
  9. Farthest Trip: Lower East Side → Crown Height North (144.1 miles)

Dashboard Features:

  1. Pages: Includes three interactive pages — Overview, Time Analysis, and Drill-through Details — allowing users to explore high-level trends and detailed records.
  2. Dynamic Measures: Built flexible DAX measures to switch between key metrics (Bookings, Booking Amount, Trip Distance) for multi-dimensional analysis.
  3. Dynamic Titles: Used DAX expressions for automatic title updates based on selected metrics and filters, ensuring contextual clarity.
  4. Slicers and Navigation: Added Date and City slicers with a Clear Filters button and Info icon for better interactivity. Implemented page navigation for seamless user experience.

Visuals:

  1. Matrix (Vehicle Type Analysis): Compares performance across vehicle types using dynamic measures. UberX led in bookings, distance, and revenue, while Uber Green showed the lowest figures.
  2. Bar Chart (Bookings by Location): Highlights top pickup locations, with Penn Station / Madison Sq West being the most frequent and preferred point.
  3. Donut Charts (Payment & Trip Type): Show customer preferences — Uber Pay made up 67% of payments, and day trips (65%) were more common than night trips (34%).
  4. Heatmap (Hour vs. Day): Displays the busiest hours and days, showing peak activity between 14:00–17:00 and higher demand on weekends.
  5. Area Chart (Daily Bookings): Tracks total bookings per day, with the 26th, 22nd, and 29th showing the highest activity.
  6. Drill-through Table: Enables users to view detailed trip-level data and KPIs for deeper analysis.

Results:

  1. Busiest Hours: Peak bookings, distance, and revenue occurred between 14:00–17:00(2PM - 5PM), showing strong afternoon demand.
  2. Peak Days: Weekends saw the highest ride activity, followed by Friday and Thursday.
  3. Top Vehicle Type: UberX led in total bookings, distance, and revenue, followed by Uber Black and Uber XL.
  4. Payment Trends: Uber Pay (67%) was most preferred, while Cash accounted for 32% of payments.
  5. Trip Type: Day trips made up 65% of total rides, showing higher daytime travel demand.
