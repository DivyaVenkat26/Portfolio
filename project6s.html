Introduction:

This project analyzes pizza sales using SQL. The objective was to extract actionable insights for operational and strategic improvements, including peak sales time, best-selling products, revenue trends, and more.

Data Preparation:

  1. Data Source: Raw transactional dataset of a fictional pizza chain.
  2. Data Platform: MySQL for query execution.
  3. Data Cleaning: Null handling, column renaming, formatting dates.

SQL Queries and Analysis:

  1. Total Revenue:

    2. Calculates total revenue earned from all pizza sales.

    SELECT ROUND(SUM(p.price * o.quantity), 2) AS total_revenue FROM pizzas AS p JOIN order_details AS o ON p.pizza_id = o.pizza_id;
  2. Total Pizzas Sold:

    3. Counts the total number of pizzas sold based on quantity ordered.

    SELECT SUM(quantity) AS Total_Pizzas_Sold FROM order_details;
  3. Average Order Value:

    4. Computes the average revenue generated per customer order.

    SELECT Round(SUM(p.price)/COUNT(DISTINCT o.order_id),2) AS Avg_Order_Value FROM pizzas as p join order_details as o on p.pizza_id = o.pizza_id;
  4. Top 3 Best-Selling Pizza:

    5. Identifies the top 3 pizzas that generated the highest revenue.

    SELECT pt.name AS Most_Ordered_Pizza,SUM(o.quantity * pz.price) AS revenue FROM pizza_types AS pt JOIN pizzas AS pz ON pt.pizza_type_id = pz.pizza_type_id JOIN order_details AS o ON o.pizza_id = pz.pizza_id GROUP BY name ORDER BY revenue DESC LIMIT 3;
  5. Hourly Demand:

    6. Shows which hours of the day have the highest pizza order quantities.

    SELECT HOUR(orders.time) AS Hour, SUM(quantity) AS Total_Quantity FROM orders JOIN order_details ON orders.order_id = order_details.order_id GROUP BY Hour ORDER BY Total_Quantity DESC;
  6. Peak Days:

    7. Finds which days of the week have the highest number of pizzas ordered.

    SELECT DAYNAME(orders.date) AS Day,SUM(order_details.quantity) AS Total_Quantity FROM orders JOIN order_details ON orders.order_id = order_details.order_id GROUP BY Day ORDER BY Total_Quantity DESC;

KPIs:

  1. Total Revenue: $817,860.05

  3. Average Order Value: $37.56

Key Insights:

  1. 🍕 **Classic Deluxe** is the top-selling pizza.
  2. 📅 **Friday** shows the highest sales volume.
  3. ⏰ **Mid-Day (12-1 PM)** shows the highest demand.
  4. 🧾 Average Order Value is close to $40, indicating high-ticket size.
