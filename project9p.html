Airline Loyalty Program Analysis

Python Project

  1. Home
  2. Airline Loyalty Program

Introduction

This project focuses on analyzing an airline’s loyalty program data to understand customer behavior, track revenue, and uncover insights that can help improve engagement and retention strategies. The analysis was done using SQL for data connection and Python for cleaning, transformation, and visualization.

Objective

  • Connect SQL database and import airline loyalty data into Python.
  • Clean the dataset and check for consistency.
  • Analyze customer demographics, loyalty tiers, and booking behavior.
  • Use visualization libraries (Matplotlib & Seaborn) to reveal revenue patterns and customer insights.
  • Identify high-value customer segments and provide recommendations to improve retention.

Methodology

  1. Data Collection

    Data was extracted from a MySQL airlines database using Python's mysql.connector. The connection enabled querying key tables such as calendar, customer_flight_activity, customer_loyalty_history.

  2. Data Integration

    Multiple SQL tables were joined in Python using pd.read_sql() to create a comprehensive dataset combining customer flight activity, loyalty history, and calendar information.

  3. Data Cleaning

    Checked dataset for consistency.

    Handled missing values and duplicates.

    Removed unnecessary spaces from column names to make analysis easier.

  4. Data Transformation

    New column: Total Revenue = Miles Redeemed × Cost Per Mile. Data types were adjusted using astype().

  5. Exploratory Data Analysis (EDA)

    • Customer Distribution: Counted customers by loyalty tier to see which tiers are most common.
    • Flight Activity: Identified the month and season with the highest flight activity.
    • Revenue Analysis: Tracked revenue over time by loyalty tier to see which tiers contribute most.
    • Top Customers: Found top 10 customers by number of flights and top 10 by revenue.
    • Points vs. Cancellations: Studied the relationship between points redeemed and flight cancellations.

Results

  1. Most flights happen in June, July, and August, followed by December and May, showing that people travel more in summer and holidays.
  2. The Star loyalty card generates the highest revenue, followed by Nova and Aurora, showing that higher-tier customers contribute much more to total revenue, highlighting the importance of retaining premium members.
  3. Customers across all loyalty tiers—Nova, Star, and Aurora—take roughly the same number of flights on average, around 1.29–1.30, suggesting that flight frequency is similar regardless of loyalty tier.
  4. The Aurora loyalty card has the highest cancellation rate, followed closely by Nova and Star, indicating that lower-tier customers cancel slightly more often, though overall cancellation rates are fairly similar across all tiers.
  5. Active customers redeem more points per person, but cancelled customers contribute to a higher total points redeemed.
  6. Focus on retaining and rewarding premium customers, as they contribute the most revenue and have the greatest impact on overall loyalty program success.
